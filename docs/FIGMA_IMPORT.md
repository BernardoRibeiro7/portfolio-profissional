# Wireframes no Figma

O laboratório pede wireframes de média fidelidade no Figma. O board SVG foi importado e o protótipo compartilhável já está disponível.

## Arquivo principal

`docs/wireframes/figma-board.svg`

## Link do protótipo

## Passo a passo de importação

1. Acesse o Figma e crie um arquivo novo.
2. Arraste `figma-board.svg` para dentro do canvas.
3. Se preferir trabalhar cada tela separadamente, importe também os quatro SVGs individuais da pasta `docs/wireframes/`.
4. Renomeie o arquivo para `LAB01 - Portfólio Profissional - Bernardo Machado`.
5. Clique em **Share** e configure a visualização por link.
6. Copie o link compartilhável e mantenha-o também no `README.md`.

Os SVGs preservam formas e textos, então podem ser ajustados dentro do Figma depois da importação.
